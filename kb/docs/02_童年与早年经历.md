# 杨幂 童年与早年经历（名字由来、北京胡同童年、童星出道）

杨幂出生成长、名字由来、童年性格和如何进入演艺圈。

1986年，杨幂出生在北京市宣武区（已并入新的北京市西城区）的一个民警家庭。因为一家三口都姓杨，也就是“杨”的3次方（数学中乘方的结果叫做幂），所以给她起名杨幂。
杨幂是地道的北京南城胡同小妞，家住在牛街附近，小时候的她还是个体育健将，最喜欢去陶然亭公园，打乒乓球、打羽毛球、游泳、滑冰，样样擅长，小杨幂从小就是个坐不住的假小子脾气，在老北京的胡同里上树爬墙，杨幂父母按照惯常家长们会采取的教育模式，带着小杨幂去学学钢琴、唱歌、画画，培养一下女儿的业余爱好，但是她却静不下心来学习东西，为此，杨幂的父母非常伤脑筋，正巧此时，儿童电影制片厂召开儿童影视表演培训班，杨幂父母抱着参与试试的心态带着杨幂去报名，结果年龄不足的小杨幂却因为聪明可爱的模样让招生老师决定破格录取。
杨幂小学就读于北京宣武实验小学（已不存在），因为成绩拔尖，从一年级到三年级，她都是班里的班长。同时，杨幂还有一个“小厉害”的外号，这是她在邻居、朋友之间获得的，因为她正义感十足，在她的概念里做错事就要被惩罚，无论是班级里、邻里之间还是朋友之间，只要朋友被欺负，总会一马当先为自己的朋友打抱不平。
