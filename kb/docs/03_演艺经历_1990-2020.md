# 杨幂 演艺经历（1990年—2020年：童星出道到走红、转型）

杨幂从童星出道、北电求学、《神雕侠侣》《仙剑三》《宫锁心玉》走红，到《三生三世十里桃花》等代表作的历程。

### 1990年-1993年：初生牛犊
1990年，杨幂参加中国儿童电影制片厂的儿童影视表演培训，正逢陈家林导演的电视剧《唐明皇》剧组来挑小演员，4岁的杨幂有幸被选中饰演幼年咸宜公主，该剧播出后获得第11届“金鹰奖”优秀长篇连续剧奖、第13届“飞天奖”长篇特等奖。1991年，5岁的杨幂迎来大荧幕首秀。参演周星驰主演的香港古装动作喜剧片《武状元苏乞儿》，饰演男主角苏灿女儿，由此开启了自己的演艺之路。虽然当时杨幂并不知名，但她拍戏时认真的态度却给《猴娃》的导演兼制片人李小婉留下了深刻印象。1993年，杨幂在李丹阳的《穿军装的川妹子》MV中饰演小李丹阳，而该作品则荣获了首届中国音乐电视大赛金奖。1996年，她与何晴、李亚鹏共同出演青春电影《歌手》，饰演小夏表妹的角色，此后她的童年演艺生涯宣告结束。


### 2001年-2010年：锋芒渐显
2001年，15岁的杨幂在北京市第十四中学读初二。她在同学的建议下把自己的照片寄给了《瑞丽》时尚杂志社，在被编辑选中后开始做起了平面模特的工作。
2002年，杨幂签约李小婉、李少红共同创办的北京荣信达影视艺术有限公司。
2003年9月，17岁的杨幂在电视剧《红粉世家》中饰演性格鲜明的小妹一角；2005年她出演的电影《北京童话》上映，在其中饰演一位身患白血病的女孩朱珠。
2004年6月，还在北京市第十四中学读高二的杨幂接演《神雕侠侣》里的郭襄一角。该剧在香港地区开播后，“小东邪”郭襄深得香港观众喜欢。香港观众盛赞杨幂是有史以来最清纯的郭襄。
2005年，杨幂以专业课第一的成绩考入北京电影学院表演系，开始接受系统的影视训练。同年，刚在影视圈崭露头角的杨幂，从3000名女生中脱颖而出，击败范冰冰、李冰冰、高园园夺得电视剧《王昭君》中“王昭君”这个角色。。12月13日，杨幂参演的古装奇幻剧《新聊斋志异》播出，在剧中饰演聂小倩一角。
2006年杨幂一边拍戏一边还要兼顾电影学院的学习。“周一到周六都在学校学习，只有周日可以回家睡觉，完全没有自己的时间”，尽管很累，她还拍摄了电视剧《相逢何必曾相识》，又与陈坤等合作出演了惊悚悬疑电影《门》。
2007年，杨幂在表演课年度考试作品《北京人》中饰演了温婉和善又沉默忧伤的愫方，由于一直片场考场两头赶，她于同年6月在拍摄电视剧《笑着活下去》的一场“床戏”时竟累到睡着。同年6月，她在北京电影学院表演系05级学生表演专业课汇报演出中领衔主演了独幕剧《青春禁忌游戏》，并在剧中饰演了拜金女高中生“拉拉”。12月，她在北京电影学院表演系年终舞台剧《楼梯的故事》中反串饰演了一个小男孩。
2008年1月6日，杨幂参演的电视剧《上书房》登陆央视八套黄金档，她在其中饰演富察家敦儿一角，该角色一改往日角色的活泼可爱，在带给杨幂一份挑战的同时，更带给了影迷一份惊喜。
2008年7月杨幂被李少红钦点在新版电视剧《红楼梦》中饰演“古典辣妹”晴雯一角，新版《红楼梦》是真正让杨幂成长的作品，她不再本色出演，而把以往揉碎了，重新塑造了一个自我。8月21日，杨幂又凭借《王昭君》入围第24届中国电视金鹰奖“最佳女主角”提名初选名单。与此同时，杨幂通过网络票选成为《仙剑奇侠传三》女主雪见的扮演者。除此之外，杨幂还在这一年出演了爱情剧《暗香》。
2009年是杨幂事业的转折点，4月，在由百万民众参与，近百名娱乐记者联合票选的“80后新生代娱乐大明星”评选中，杨幂与黄圣依、王珞丹、刘亦菲共同获得了内地新“四小花旦”的称号。之后，由杨幂主演的电视剧《仙剑奇侠传三》播出，她在剧中一人分饰了性格和气质截然不同的夕瑶和雪见，由于两个角色细节的表演拿捏十分到位，再加上角色性格讨喜，杨幂在这一年成为了众多网络票选中最受欢迎的明星。同年，她还出演了古装传奇宫斗剧《美人心计》，并在剧中饰演了窦漪房身边忠心耿耿、武功高强的贴身侍女，由于出色的表演，钦点她出演雪鸢的《美人心计》制片人于正大赞她：“沉静如安然之秋水”，并预言她下一站一定是天后。
2010年年初，在与荣信达影视的合约到期后，杨幂签约香港美亚娱乐，随后杨幂的事业呈多栖化发展，不仅所主演的电视剧《神探狄仁杰前传》和《美人心计》均创下收视新高，还推出了自己进军歌坛的第一支歌曲《琉璃月》，在拍电视剧唱歌之余，她更马不停蹄狂见中国香港多位著名导演和制片人。同年，她还出演现代都市言情剧《北京爱情故事》，该剧令其获得了第26届中国电视金鹰奖“最具人气女演员”奖。此外，她还出演了好莱坞魔幻片《人鱼帝国》。


### 2011年-2016年：创造辉煌
2011年，杨幂主演的宫斗穿越剧《宫锁心玉》在湖南卫视播出后掀起热潮，收视率屡创新高且位居全国同时段收视率第一，获得上亿次网络播放量，杨幂凭借在剧中饰演的意外回到康熙晚期的二十一世纪美少女洛晴川一角大红一把，其个人则凭借该剧首次登上了福布斯中国名人榜，获得了第17届上海电视节白玉兰奖观众票选最具人气女演员奖，并且获得了最佳女演员奖提名，而由她演唱的《宫》剧主题曲《爱的供养》则登上了中国内地多个试听网站的冠军位置。7月8日，杨幂主演的电影《孤岛惊魂》上映，出演了热爱探险、性格独立的靓丽美女沈伊琳。一向以清纯形象示人的杨幂为演好片中角色，在片中突破尺度，以性感比基尼扮相出场，这一突破也让她备受关注。虽然口碑欠佳，但凭借粉丝力量，这部小成本电影最终传创下了9000万的国产恐怖片票房纪录。演而优则唱，9月12日，杨幂在香港与少城时代签约，同时加盟环球唱片，跨界成为歌手。同年，杨幂入围第二届中国大学生电视节“最受大学生瞩目”女演员。10月21日，杨幂与张庭合作的古装悬疑剧《唐宫美人天下》播出。
在谷歌年度全球热门搜索关键词中国地区人物搜索榜单中排名榜首；自身实力壮大后，杨幂决定自己当老板，2012年伊始，杨幂工作室成立，1月4日，她的首张个人音乐专辑《亲幂关系Close to Me》正式发行。11月9日，杨幂参与根据郭敬明同名小说改编并由他自编自导的《小时代》系列电影的拍摄工作，她在片中饰演了性格温和善良、胆小怕事却又从不气馁，有点小迷糊的“爱哭”女孩，但最终成长为能够独当一面的励志姐的第一女主角林萧。
2013年，《小时代》《小时代2：青木时代》陆续上映，虽然影片遭遇了极大的争议，但仍在暑期档砍下了近8亿元的票房；2014年7月17日《小时代3：刺金时代》上映；2015年7月《小时代4：灵魂尽头》上映，而随着《小时代》系列电影的完结，其最终票房成绩超过了18亿人民币，并创造了国产系列电影的票房纪录。
2014年7月2日，她主演的仙侠偶像剧《古剑奇谭》在湖南卫视播出，在剧中饰演的风晴雪与男主角百里屠苏相爱却不能相守的结局让观众落泪。该剧播出后不断刷新国内周播剧的收视纪录，稳居全国网收视冠军，也是第一部网播破100亿的电视剧，单集平均点击量突破1.5亿，单日播放量9447万。同年参演的电影《分手大师》也取得了不错的成绩
2015年10月30日，她主演的电影《我是证人》票房2.15亿，在片中饰演的盲女是她出道以来最复杂的角色，她也在这部影片中给观众贡献了较好的演技。
2016年，杨幂再战大荧幕，主演了古装动作片《绣春刀Ⅱ：修罗战场》，她在片中饰演了命运坎坷的画师北斋，并凭借此片获得北京大学生电影节最受大学生欢迎女演员奖；6月，其主演的职场爱情剧《亲爱的翻译官》在湖南卫视开播即迎来收视开门红，各大实时数据和收视数据均排同时段第一，她在其中饰演的角色乔菲，不仅是学习成绩全优的学霸，骨子里更透露出一股倔强与不服输的精神，而该剧自开播以来就保持较高热度，曾创造全国网单集破4的记录，更凭借双网破2的收视率取得了全国年度电视剧收视冠军。同年9月30日，她参演的电影《爵迹》上映，截止到2022年12月25日，该电影在豆瓣有超过15.3万人评分，评分3.8分，该电影收获了3.83亿的票房。
在电视剧领域创造高热度的同时，杨幂的荧幕之旅却不太顺遂，2016年3月，杨幂凭《小时代4：灵魂尽头》《何以笙箫默》两部电影获得第七届中国电影金扫帚奖最令人失望女演员奖，这是她第三次获得该奖项。2013年以《大武当之天地密码》《hold住爱》首次成为最令人失望女演员，2015年她又借《小时代3：刺金时代》《分手大师》再度封后。


### 2017年-2021年：寻求突破
2017年春节档。春节档，杨幂主演的大型神话仙恋电视剧《三生三世十里桃花》在东方卫视、浙江卫视上星播出，她在剧中饰演了绝美明艳，敢爱敢恨的青丘九尾狐族上神白浅，该剧在收官时收获双台连续破1的收视成绩、一路高歌逼近300亿网播数据。也是在这一年，杨幂凭借《逆时营救》获得第50届休斯顿国际电影节最佳女主角奖。，这也是她拿下的首个国际电影节最佳女主角奖项，而该奖项的含金量却引起了网友的质疑。2017年12月2日，杨幂参加《2018爱奇艺尖叫之夜》。2018年2月，杨幂主演的都市情感剧《谈判官》首播获得收视破1的好成绩，剧中杨幂饰演了一位在职场中风生水起、意气风发的女强人童薇；6月18日，杨幂主演的电视剧《扶摇》在浙江卫视上星播出，其在剧中饰演了平凡却努力蓄积力量成长的扶摇；同年10月19日，她主演的剧情电影《宝贝儿》票房惨淡，但是在拍摄该电影时做出的努力得到了导演的肯定。12月28日，杨幂获得了第五届中国电视好演员奖绿宝石女演员奖。
2019年杨幂成为芒果TV室内真人秀《密室大逃脱》的常驻嘉宾，5月6日，杨幂和霍建华联袂主演的电视剧《筑梦情缘》在湖南卫视金鹰独播剧场正式开播。6月21日，杨幂参加湖南卫视全球顶尖才艺秀《巅峰之夜》。2019年10月30日，杨幂参加综艺节目《脱口秀大会》，节目由《吐槽大会》原班人马打造。
截止到2022年12月25日，《谈判官》豆瓣评分3.5分，《扶摇》豆瓣评分4.7分，《筑梦情缘》豆瓣评分4.6分，三部电视剧的口碑均没有达到理想成绩。
2020年2月24日，杨幂参与合唱的人民战”疫“公益MV《祝你平安，2020》上线。2020年6月30日，杨幂续约《密室大逃脱》，参与第二季的录制；同年9月15日，杨幂提名第30届中国电视金鹰奖观众喜爱的女演员奖。12月20日，杨幂参加《2020腾讯视频星光大赏》。
